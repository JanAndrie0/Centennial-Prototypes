# Centennial Sales and Inventory System — clickable prototype

Web-based sales and inventory prototype for Centennial Nail and Screw Construction Corporation (UE BSIT capstone).
Plain HTML, CSS and JavaScript with sample data. Nothing to install.

## Open it

1. Download the project (green **Code** button → **Download ZIP**) and unzip it, or clone it.
2. Double-click `login.html` (or `index.html`) to open it in Chrome or Edge.
3. On the login page, open **Demo: log in as…** and pick a role (CEO, Office Manager, Sales Supervisor, Admin / Warehouse Staff, Sales Agent).
   All demo accounts use the password `centennial`.

Changes are saved in your browser only. Use **Reset demo data** at the bottom of any page to start over.

## What's in here

- `login.html`, `dashboard.html` — login and home screen
- `users/`, `products/`, `customers/`, `payments/`, `orders/`, `deliveries/`, `purchasing/`, `reports/` — the modules
- `m/` — the sales agent's phone screens
- `assets/` — shared styles, scripts, icons and the logo
- `docs/` — module plans and the build order
